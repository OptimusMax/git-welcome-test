# git-welcome-test

Тестовий репозиторій для роботи з Git і Claude Code.

## Що тут налаштовано

- **Плагіни з [anthropics/skills](https://github.com/anthropics/skills)** (`.claude/settings.json`): `document-skills` (Word, PDF, PowerPoint, Excel) та `example-skills` (skill-creator, mcp-builder, frontend-design, webapp-testing тощо). Claude Code запропонує встановити їх, коли ви відкриєте проєкт.
- **Навичка `git-helper`** (`.claude/skills/git-helper/SKILL.md`): покроковий помічник з Git українською — коміти, гілки, push/pull і розбір типових помилок.
