# Dubber — автоматичний дубляж відео

Програма бере відео будь-якою мовою і створює дубльовану версію (за замовчуванням українською):

1. **Розпізнавання мовлення** — [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (локально, з таймкодами)
2. **Переклад** — Google Translate через `deep-translator`
3. **Озвучення** — нейронні голоси Microsoft Edge TTS (`uk-UA-OstapNeural`, `uk-UA-PolinaNeural` тощо)
4. **Синхронізація** — кожна фраза ставиться на свій таймкод; задовгі фрази прискорюються без зміни тону (до `--max-speed`), а якщо й це не допомагає — наступні фрази зсуваються без накладань
5. **Зведення** — нова аудіодоріжка + тихий фон оригіналу + вбудовані субтитри; відеопотік копіюється без перекодування

## Встановлення

Потрібні Python 3.10+ та [ffmpeg](https://ffmpeg.org/download.html) у `PATH`.

```bash
pip install -e .
```

## Використання

```bash
# Дубляж українською (мова оригіналу визначається автоматично)
dubber video.mp4

# Одразу з YouTube (відео завантажиться автоматично)
dubber "https://youtu.be/VIDEO_ID"

# Жіночий голос, інший вихідний файл
dubber video.mp4 -o video_ua.mp4 --female

# Дубляж англійською, точніша модель розпізнавання на GPU
dubber video.mp4 -t en --model medium --device cuda

# Лише дубляж без фонового звуку, але зберегти оригінальну доріжку другою
dubber video.mp4 --bg-volume 0 --keep-original
```

### Ручне редагування перекладу

Після запуску поруч із відео з'являються `*.orig.srt` (оригінал) і `*.uk.srt` (переклад).
Виправте переклад і переозвучте без повторного розпізнавання:

```bash
dubber video.mp4 --translated-srt video.uk.uk.srt -o video_fixed.mp4
```

Якщо субтитри оригіналу вже є — `--srt original.srt` пропускає крок розпізнавання.

### Основні параметри

| Параметр | Опис | За замовчуванням |
|---|---|---|
| `-t, --target` | мова дубляжу | `uk` |
| `-s, --source` | мова оригіналу | автовизначення |
| `--voice` | будь-який голос Edge TTS (`edge-tts --list-voices`) | залежить від мови |
| `--female` | жіночий голос | вимкнено |
| `--rate` | швидкість мовлення TTS, напр. `+10%` | `+0%` |
| `--model` | модель whisper: `tiny`…`large-v3` | `small` |
| `--max-speed` | максимальне прискорення фрази | `1.35` |
| `--bg-volume` | гучність оригіналу під дубляжем (0–1) | `0.12` |
| `--keep-original` | додати оригінальну доріжку другою | вимкнено |
| `--no-subs` | не вбудовувати субтитри | вимкнено |
| `--work-dir` | зберегти проміжні файли | тимчасова папка |

## Структура

```
dubber/
  cli.py         — командний рядок
  pipeline.py    — конвеєр дубляжу
  transcribe.py  — розпізнавання (faster-whisper)
  translate.py   — переклад
  tts.py         — синтез голосу (edge-tts)
  timeline.py    — підгонка темпу та збирання доріжки
  segments.py    — сегменти та SRT
  media.py       — ffmpeg: витяг, декодування, зведення
tests/           — тести (pytest)
```

## Тести

```bash
pip install -e ".[dev]"
pytest
```

## Обмеження

- Переклад і озвучення потребують інтернету; розпізнавання працює локально (модель завантажується при першому запуску).
- Голос один на все відео — різні мовці не розділяються.
- Фоновий звук — це приглушений оригінал (разом із голосом). Для чистого фону можна попередньо розділити доріжку, напр. через [Demucs](https://github.com/facebookresearch/demucs).
